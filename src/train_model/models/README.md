# Сохранённые модели

## Что лежит

| Файл | Что это |
|---|---|
| `final_D_oof.pkl` | **рабочая модель для сервиса оценки**: обучена на всех фолдах кроме отложенного теста |
| `lgbm_D_oof_fold{0..4}.pkl` | модели по фолдам, нужны для воспроизведения метрик и анализа |
| `lgbm_F_emb16_fold*.pkl`, `lgbm_F_emb32_fold*.pkl` | то же для наборов с эмбеддингами снимка (эксперимент, в продукт не идут) |
| `nn_NN_image_fold*.pt` | веса нейросети с двумя входами: состояние лучшей эпохи, нормировки вырезок, параметры |

## Как загрузить рабочую модель

```python
import joblib
import numpy as np

bundle = joblib.load("models/final_D_oof.pkl")
model, columns = bundle["model"], bundle["columns"]

# frame - DataFrame с теми же колонками, что в columns:
# параметры квартиры + признаки дома из таблицы buildings
prediction = np.exp(model.predict(frame[columns])) * frame["area"]
```

Важно:

- `building_type` и `object_type` должны быть `category`, иначе LightGBM
  обработает их как числа и предсказание поедет;
- цель модели — `log(цена / м²)`, поэтому итоговая цена получается через
  `exp(prediction) * area`;
- `months_since_start` считается от `2018-03-01`. Данные заканчиваются маем 2021,
  поэтому при оценке подставляйте значение последнего месяца обучающей выборки,
  а результат умножайте на индекс цен (см. отчёт, раздел про индексацию);
- `house_age` может быть `NaN` — это нормально, модель обучена с пропусками.
