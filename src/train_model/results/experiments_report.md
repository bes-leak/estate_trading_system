# Эксперименты: добавляют ли данные ДЗЗ точность оценки

Дата прогона: 2026-10-14. Все эксперименты на одних и тех же 5 пространственных
фолдах (клетки 1×1 км), цель `log(цена/м²)`, метрика MdAPE, веса `1/sqrt(n_at_point)`.
Отложенный тест (`fold = -1`, 15 % клеток) не использовался при выборе моделей.

## Главный вывод

Снимки Sentinel-2 **не дают прироста точности** поверх признаков набора D
(параметры квартиры + расположение + транспорт + среда из OpenStreetMap).
Это подтверждено четырьмя независимыми способами: индексы NDVI/NDBI в буферах,
эмбеддинги энкодера ImageNet, эмбеддинги энкодера SSL4EO-S12 (предобучен
на Sentinel-2) и прямая регрессия на остатках модели D.

Рабочая модель для системы — **LightGBM на наборе D**:

| | MdAPE |
|---|---|
| кросс-валидация (5 фолдов) | **9.25 % ± 0.75** |
| отложенный тест | **9.04 %** |

Для сравнения: «оракул», знающий медианную цену м² в том же доме, ошибается
на 8.4 %. То есть модель близка к шумовому порогу данных и улучшать её
имеет смысл не признаками среды, а данными о состоянии квартиры.

## 1. Набор E: индексы NDVI и NDBI в буферах

Средние значения NDVI и NDBI в буферах 300/500/1000 м, посчитанные по летнему
композиту Sentinel-2 2021 года.

| Набор | MdAPE | Прирост к D |
|---|---|---|
| D | 9.28 % | |
| E = D + NDVI/NDBI | 9.27 % | −0.01 п. п. |

## 2. Набор F: эмбеддинги предобученного энкодера

Вырезки 64×64 (640 м) вокруг каждого дома, 10 м/пиксель, пропущены через
ResNet18 с весами ImageNet, вектор 512 сжат PCA (74 % дисперсии в 32 компонентах).

| Набор | MdAPE | Прирост к D |
|---|---|---|
| D | 9.25 % | |
| F = D + 16 компонент | 9.19 % | −0.06 п. п. |
| F = D + 32 компоненты | 9.34 % | +0.09 п. п. |

Разница внутри разброса между фолдами (±0.75 п. п.), то есть эффекта нет.

## 2б. Набор G: энкодер, предобученный на снимках Sentinel-2

То же самое, но вместо весов ImageNet взят ResNet18 из **SSL4EO-S12**
(самообучение MoCo на снимках Sentinel-2, веса torchgeo). Такой энкодер
знает текстуры земной поверхности, а не объекты из фотографий.

| Набор | MdAPE | Прирост к D |
|---|---|---|
| D | 9.25 % | |
| G = D + 16 компонент SSL4EO | 9.34 % | +0.09 п. п. |
| G = D + 32 компоненты SSL4EO | 9.19 % | −0.06 п. п. |

По фолдам G_ssl32 лучше D в 3 случаях из 5 (−0.35, +0.28, +0.33, −0.49, −0.06).
Результат неотличим от варианта с ImageNet: специализированный энкодер
ситуацию не меняет.

## 3. Регрессия на остатках модели D

Самая строгая проверка: берём остатки OOF-предсказаний D и учим LightGBM
предсказывать их по эмбеддингам снимка на тех же фолдах.

| fold | R² | корреляция | MdAPE до → после коррекции |
|---|---|---|---|
| 0 | −0.040 | −0.082 | 9.34 % → 9.88 % |
| 1 | −0.044 | −0.093 | 10.14 % → 10.52 % |
| 2 | −0.024 | +0.018 | 8.49 % → 8.71 % |
| 3 | −0.020 | +0.038 | 9.79 % → 9.79 % |
| 4 | −0.023 | +0.033 | 8.48 % → 8.86 % |
| **среднее** | **−0.030** | | **9.25 % → 9.55 %** |

R² отрицательный, корреляции на уровне нуля: снимок не содержит информации
об ошибках модели D. Коррекция делает только хуже.

Та же проверка на эмбеддингах SSL4EO: R² = −0.022, MdAPE 9.25 % → 9.43 %.
Вывод не зависит от выбора энкодера.

## 4. Нейросеть с двумя входами

Таблица (MLP) + окно снимка (CNN), поздняя конкатенация, те же фолды.

| Модель | MdAPE |
|---|---|
| LightGBM D | 9.25 % ± 0.75 |
| NN_image (таблица + снимок) | 10.97 % ± 0.66 и 11.47 % ± 2.32 в повторном прогоне |
| NN_tabular (только таблица) | 11.71 % ± 1.02 |

Нейросеть проигрывает бустингу 1.7 п. п. Свёрточная ветка улучшает сеть
на 0.74 п. п., но лишь в 3 фолдах из 5, и итог всё равно хуже бустинга.
Отдельно отмечу: первые прогоны давали 14.5 %, и причиной была предобработка.
Исправления, которые дали −3 п. п.: RankGauss вместо стандартизации
(у расстояний очень длинные хвосты), обрезка градиентов, нормировка
взвешенного лосса на сумму весов.

## 5. Ансамбль бустинга и нейросети

OOF-предсказания обеих моделей смешаны как `alpha * GBM + (1 - alpha) * NN`
в пространстве `log(цена/м²)`.

| alpha (доля бустинга) | 0.0 | 0.5 | 0.7 | **0.8** | 0.9 | 1.0 |
|---|---|---|---|---|---|---|
| MdAPE | 11.26 % | 9.53 % | 9.13 % | **9.03 %** | 9.05 % | 9.15 % |

По фолдам при alpha = 0.8:

| fold | GBM | NN | ансамбль | разница |
|---|---|---|---|---|
| 0 | 9.34 % | 10.40 % | 9.18 % | −0.17 |
| 1 | 10.14 % | 10.68 % | 9.97 % | −0.17 |
| 2 | 8.49 % | 9.89 % | 8.11 % | −0.38 |
| 3 | 9.79 % | 10.79 % | 9.70 % | −0.09 |
| 4 | 8.48 % | 15.56 % | 8.71 % | +0.22 |
| **среднее** | **9.25 %** | **11.47 %** | **9.13 %** | **−0.12** |

Ансамбль лучше бустинга в 4 фолдах из 5, выигрыш 0.12 п. п. Корреляция остатков
двух моделей 0.83: модели ошибаются похоже, поэтому большего от смеси ждать
не стоит. В фолде 4 обучение сети разошлось (15.56 %), и ансамбль там проиграл —
это же показывает главный риск: нейросеть нестабильна от запуска к запуску
(разброс ±2.32 п. п. против ±0.75 у бустинга).

**Вывод по продукту:** ансамбль даёт слишком мало, чтобы тащить в систему вторую
модель, GPU в контуре обслуживания и зависимость от вырезок снимка. В «Видении»
была идея «двух моделей на выбор» — от неё отказываемся, в отчёт идёт обоснование.

## 6. Подстановка признаков ближайшего дома

Проверка решения для конвейера: пока воркер считает признаки нового дома,
сервис подставляет значения ближайшего известного дома.

| fold | точные признаки | признаки соседа | медиана расстояния |
|---|---|---|---|
| 0 | 9.34 % | 9.49 % | 12 м |
| 1 | 10.14 % | 10.27 % | 12 м |
| 2 | 8.49 % | 8.69 % | 37 м |
| 3 | 9.79 % | 9.76 % | 42 м |
| 4 | 8.48 % | 8.46 % | 29 м |
| **среднее** | **9.25 %** | **9.33 %** | |

Потеря точности 0.08 п. п. — подстановка соседа оправдана: оценку можно
показывать сразу, не дожидаясь воркера, пометив её как приблизительную.

## Что это значит для системы

1. **Основная модель — LightGBM на D.** Нейросеть в продукт не идёт,
   в отчёт идёт как проверенная и отклонённая гипотеза.
2. **Критерий 6 «Видения» выполняется средовыми признаками OSM** (промзоны,
   зелень, вода, дороги), а не данными ДЗЗ: переход C → D даёт −0.20 п. п.
   в 4 фолдах из 5. Спутниковые индексы и эмбеддинги прироста не дают,
   и это нужно честно зафиксировать в документации.
3. **Подстановка признаков соседа разрешена** и почти бесплатна (+0.08 п. п.).
4. **Ансамбль с нейросетью не оправдан**: +0.12 п. п. ценой второй модели,
   GPU и нестабильности обучения.

## Чего эксперименты не проверяли

- Другие спутниковые энкодеры (Prithvi, DOFA): проверен только SSL4EO-S12 ResNet18
  по каналам RGB. Вариант на все 13 каналов не проверялся, так как в вырезках
  сохранены только 4 канала по 10 м.
- Снимки за 2021 год для вырезок: сейчас используется съёмка 2026-08-23,
  тогда как цены относятся к 2018–2021.
- Разрешение выше 10 м (коммерческие снимки).
